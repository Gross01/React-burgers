# Stellar Burger

Проект **Stellar Burger** — это интерактивное приложение, где вы можете самостоятельно собрать свой уникальный бургер из различных ингредиентов и оформить заказ.

## Возможности
- Выбор и сборка бургера из разных ингредиентов
- Просмотр состава и стоимости заказа в реальном времени
- Оформление заказа с подтверждением
- Авторизация и история заказов

## Установка и запуск

Для запуска проекта локально выполните команды:

```bash
# Установка зависимостей
npm install

# Запуск проекта в режиме разработки
npm start

# Запуск unit-тестов
npm test

# Запуск интеграционных тестов
npm run cypress

# Сборка и деплой проекта
npm run deploy
